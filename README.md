# x-xbps
Оболочка для xbps и помогающая удобно устанавливать, удалять и пакеты с помощью команды x

Команды:

```
x     - Установка пакетов (xbps-install)
x -S  - Установка с синхронизацией (xbps-install -S)
x -Su - Полное обновление системы (xbps-install -Su)
x -s  - Поиск пакета в репозиториях (xbps-query -Rs)
x -R  - Принудительное удаление (xbps-remove -RFdf)
x -O  - Чистка кэша и сирот (xbps-remove -Ooy)
```
